# Machine Learning Lab Practicals

## About
This repository contains my Machine Learning Lab practicals implemented using Python in Jupyter Notebook.

The practicals cover different supervised machine learning algorithms, regression, classification, decision trees, ensemble learning and neural networks.

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Software Requirements
- Python 3
- Anaconda Navigator
- Jupyter Notebook

## Installation

Install the required libraries using:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

## How to Run
1. Clone or download this repository.
2. Open Anaconda Navigator.
3. Launch Jupyter Notebook.
4. Open the required `.ipynb` file.
5. Run the cells one by one.

## Learning Outcomes
- Understand basic machine learning algorithms.
- Perform data preprocessing and analysis.
- Train and test machine learning models.
- Make predictions using trained models.
- Evaluate model performance using accuracy, MSE and R² score.
- Visualize datasets and model results.
